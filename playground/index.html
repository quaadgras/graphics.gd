    How it works
    
    
      
  1. The go command of compiler.gd, built for GOOS=js, compiles and links your program in a worker.
    2. 
      
  2. The program runs on the WebAssembly GC beside the Godot engine (graphics.gd's web build of it), which it calls directly; each run starts the engine again in a frame.
    3. 
      
  3. graphics.gd's source is in the page's file system. The packages that the examples use come precompiled; a class that none of them uses is compiled when you first import it, which takes a few seconds, and is then kept.
    4. 
      
  4. The build cache lives in IndexedDB; the downloads are kept in the browser's Cache Storage.
    5. 
      
  5. The standard library and graphics.gd only (no other modules), and one file. Ctrl+Enter runs.
    6. 
      
  6. Needs WebAssembly GC and JSPI: Chrome 137, Firefox 153, Safari 27.
    7.
